Across the UK, only a limited number of laboratories measure A4; most of these use LC‐MS/ MS for analysis with the rest using immunoassay (UK NEQAS, Table S3). In general, A4 immunoassays display a positive bias when compared to LC‐MS/MS (UK NEQAS, Figure S4). This has been attributed to non‐specific antibody‐antigen interactions and poor standardisation . However, like T, LC‐MS/MS A4 assays are prone to variation due to differences in sample prep- aration and calibration . A4 levels may also vary signifi- cantly across the menstrual cycle. Recommendations: A4 should be measured in all patients being investigated for suspected androgen excess. A4 should be measured using a well validated LC‐MS/ MS method, where possible If using immunoassay for analysis, consider validation using an LC‐MS/MS method where the biochemical findings do not align with the clinical picture. All results should be interpreted against evidence‐based reference ranges. These should be categorised as either age‐specific and/or pre‐ and post‐menopausal.
